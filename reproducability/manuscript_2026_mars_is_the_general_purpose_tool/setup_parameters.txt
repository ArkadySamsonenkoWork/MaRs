The time benchmarking described in the main text and supplementary materials was performed on a workstation running Ubuntu 22.04.5 LTS (64-bit), equipped with a 12th Gen Intel® Core™ i5-12600KF processor (6 performance cores + 4 efficiency cores, 16 threads total), 64 GB DDR5 RAM (Kingston Fury Beast KF552C40BBAK2-64, 2 × 32 GB), and a Samsung SSD 980 PRO 1 TB storage drive. The software environment comprised Python 3.10.12, NumPy 1.26.4, PyTorch 2.3.1, and MaRs (mars_epr version 0.0.6.post5). MATLAB (2022a release) and EasySpin 6.0.12 were used for MATLAB-based calculations. GPU computations, when performed, utilized an NVIDIA RTX 4080 with CUDA 12.6. All computations presented in the main text were executed using float64 for real numbers and complex128 for complex values on a CPU device.
